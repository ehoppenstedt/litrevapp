# Sample Data

This folder contains sample documents used for testing and demonstration purposes.

## Files

### bloom-two-sigma.pdf
- **Title:** The 2 Sigma Problem: The Search for Methods of Group Instruction as Effective as One-to-One Tutoring
- **Author:** Benjamin S. Bloom
- **Journal:** Educational Researcher, Vol. 13, No. 6 (Jun. - Jul., 1984), pp. 4-16
- **Source:** https://web.mit.edu/5.95/www/readings/bloom-two-sigma.pdf
- **Description:** Classic educational research paper about the effectiveness of tutoring vs. group instruction

This paper is automatically loaded as a sample source when the app runs for the first time, creating a demo project called "Cognitive Load in HCI" with sample highlights and notes.

## Usage

On first launch, the app will:
1. Create a sample project with research question
2. Copy this PDF to the app's Documents folder
3. Create sample excerpts and highlights
4. Populate the Notes & Excerpts with formatted text

To reset the sample data:
- Delete and reinstall the app, or
- Clear the `hasSampleData` key from UserDefaults
